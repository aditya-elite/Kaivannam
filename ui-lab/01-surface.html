Study 01

Surface & material

The single biggest gap between the current build and the reference is that our surfaces are perfectly flat. Handloom, block print and kalamkari have no flat surfaces anywhere. This is also the cheapest category to fix — most of it is one pseudo-element.

body::before currently paints a 22px dot grid at 5% indigo. It reads as graph paper. Cloth has two thread axes at different periods, and the warp is warmer than the weft.

/* globals.css — replaces the dot-grid background-image */
body::before {
  background-image:
    repeating-linear-gradient(90deg, rgba(107,85,70,.055) 0 1px, transparent 1px 7px),
    repeating-linear-gradient(0deg,  rgba(107,85,70,.038) 0 1px, transparent 1px 9px);

7px and 9px are coprime, so the two axes never align into a visible grid. The slubs (those three short thicker threads) are absolutely-positioned 1px spans placed by a seeded index — the same trick as rough.ts. Three per viewport is plenty; more reads as dirt.

Costs one repaint on a fixed element that never scrolls.

3 · Deckled paper edge

Torn edge via mask, not clip

data URI
The maker's story

"My grandmother taught me this border. It takes four days."

A mask rather than a clip-path, because a mask can be soft at the boundary while a clip is always a hard cut. Handmade paper edges are fibrous, not sharp.

Best reserved for the story card, where the paper metaphor is doing narrative work. Applied everywhere it becomes a gimmick within one screen.

One placement only.

4 · Dye-lot variance

Natural dye lots never match. Eight identical terracotta swatches read as machine output; eight swatches drifting ±4° hue and ±3% lightness read as dyed. This is the roughness argument applied to colour instead of shape.

Repeated fills

seeded helper
Flat — one hex
Dye-lot — seeded drift
// lib/dyelot.ts — reuses the hash from rough.ts
export function dyeLot(index: number, seed = 0) {
  const h = hash(index, seed);
  const hue = 17 + ((h % 9) - 4);        // ±4°
  const lig = 41 + (((h >> 8) % 7) - 3); // ±3%
  return `hsl(${hue} 86% ${lig}%)`;
}
Contrast is the catch. Drifting lightness drifts contrast. Clamp the range so the darkest lot still clears 4.5:1 against white text — ±3% is safe against terracotta, ±6% is not.

Verify outdoors on a cheap LCD before committing.

Two 1px shadows, no blur, no filter. Works only on the cream — on white it disappears, on indigo it inverts wrongly. And only on display sizes: at 16px the highlight fringe starts eating the glyph and body text gets measurably harder to read.

Display type on cream grounds. Never body copy.

6 · Selvedge strip

Woven edge as a section rule

CSS only
A denser, more literal cousin of the sawtooth thread already used on the tab underline. Useful as the top edge of the footer or a Tier A section break — somewhere it can be large enough to read as weave rather than as noise.

Cheap, on-vocabulary, no JS.

The one I'd skip. Paper curl shadows on cards — the corner-lift effect. It needs a blurred, animated box-shadow, which the motion spec forbids outright, and it reads as 2011 skeuomorphism rather than as craft. The texture ideas above get you the same warmth without the baggage.
